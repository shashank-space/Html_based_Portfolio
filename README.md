# Personal Portfolio Website

This is a simple portfolio website created using Only HTML.

## Author
**Shashank Shekhar Prakash**
*Aspiring Web Developer*

## Features

- **Semantic Structure:** Built using HTML5 semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<header>`, `<footer>`) for better SEO and accessibility.
- **Navigation:** Fully functional internal links to jump between the About, Skills, and Contact sections.
- **Personal Branding:** Includes a profile image and professional bio.
- **Interactive Contact Form:** A user-friendly form with input validation for names and emails.
- **External Links:** Footer includes direct links to my GitHub profile and a mailto link for direct communication.

## Technologies Used

- HTML5

## How to Run

1. Download the project
2. Open index.html in your browser Or run the Code in your VS code of index.html file.
